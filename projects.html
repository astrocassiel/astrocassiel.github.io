Projects

A collection of technical and creative projects spanning thermal imaging, data processing, simulation, and design.

Selected Projects

Two-Color Thermography Simulation Tool

A modeling and analysis tool developed to study two-color thermography performance under varying spectral bands, emissivity behavior, and experimental conditions. This project helped evaluate how optical choices influence temperature sensitivity and measurement robustness.

  • MATLAB / Julia
  • Thermal radiation modeling
  • Sensor and filter optimization

WAAM Thermal Data Visualization Pipeline

A data processing and visualization workflow built to analyze wire arc additive manufacturing experiments. The pipeline organizes thermal history, melt pool geometry, cooling rates, and mechanical property data into publication-ready plots and comparative figures.

  • MATLAB / Python
  • Thermal + hardness data analysis
  • Automated plotting workflows

Custom Dual-Sensor Camera Processing Scripts

A set of scripts created to process visible and near-infrared data from dual-sensor imaging systems. The workflow supports frame import, channel extraction, ratio calculations, calibration analysis, and preparation of stitched datasets for temperature-related studies.

  • Python / MATLAB
  • RGB + NIR processing
  • Calibration and ratio analysis

3D Printed Art and Functional Design Pieces

A growing collection of personal fabrication projects that combine aesthetics with practical design. These include decorative prints, small functional objects, and concept pieces created through CAD modeling and iterative prototyping.

  • CAD and 3D printing
  • Rapid prototyping
  • Creative fabrication

Experimental Imaging and Calibration Setups

A series of custom experimental setups built for thermal imaging, camera calibration, and signal validation. These projects involved practical optical alignment, exposure studies, spectral considerations, and custom workflows for extracting reliable measurements in harsh environments.

  • Optical experimentation
  • Camera calibration
  • Measurement validation
